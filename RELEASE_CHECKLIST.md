# DeepChat Release Checklist

Before creating a new installer or portable build:

1. Stop running `DeepChat*` processes so old release artifacts are not locked.
2. Run `npm test`.
3. Run `npm run build`.
4. Run `npm run verify`.
5. Run `npm audit --omit=dev --registry=https://registry.npmjs.org`.
6. Run `npm run release:sbom` and confirm `release/sbom.cdx.json` validates as CycloneDX.
7. Run `npm run release:checksums` and confirm `release/SHA256SUMS.txt` includes every uploaded `.exe`, `.blockmap`, `.yml`, and `sbom.cdx.json` artifact.
8. Run `npm run release:smoke` after building portable artifacts; it should launch the portable app and keep it alive through the smoke window.
9. Launch the built app manually and smoke test: send text, attach an image with a vision model, run a code block, use web search, open a Mermaid diagram, and import/export a backup.
10. Confirm artifact names follow `DeepChat-Setup-vX.Y.Z.exe` and `DeepChat-Portable-vX.Y.Z-YYYYMMDD-HHMMSS.exe`.
11. Confirm the GitHub workflow produced artifact provenance attestations for executables, update metadata, checksums, and SBOM.
12. Update `CHANGELOG.md` with the user-visible changes.
13. For GitHub releases, push a `vX.Y.Z` tag and review the draft release generated by `.github/workflows/release.yml` before publishing.

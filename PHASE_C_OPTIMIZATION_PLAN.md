## 六、风险与注意事项

1. **chat.ts 拆分风险**: 3360行文件是项目核心，拆分需极度小心，建议逐个函数迁移，每次迁移后全量测试
2. **electron 严格化风险**: `tools.js` 2494行 JS → TS 是个大工程，建议渐进式，先加 JSDoc 类型注释
3. **性能优化回归**: 虚拟滚动、缓存等改动需充分测试边界情况（空对话、单条消息、千条消息）
4. **Mermaid 按需加载**: 需确认各 diagram 类型的依赖关系，避免懒加载后某些图表无法渲染
5. **localStorage → IndexedDB 迁移**: 需写迁移脚本，防止用户数据丢失

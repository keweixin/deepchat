name: Release Checklist
description: 发布前检查清单
---

你是一位发布管理专家。请根据提供的项目信息，执行发布前的全面检查。

## 检查清单

### 1. 代码质量

- [ ] 所有自动化测试通过（单元测试、集成测试、E2E 测试）
- [ ] 测试覆盖率满足最低要求（建议 80%+）
- [ ] 代码审查已完成，所有 CRITICAL/HIGH 问题已修复
- [ ] 静态分析（lint、typecheck）无错误
- [ ] 无遗留的 `console.log`、调试代码或 TODO 注释

### 2. 安全检查

- [ ] 无硬编码的密钥、密码或 Token
- [ ] 依赖项无已知高危漏洞（npm audit / pip audit）
- [ ] 敏感数据处理符合脱敏规范
- [ ] 输入校验和输出转义已到位
- [ ] 权限控制遵循最小权限原则

### 3. 版本与变更

- [ ] 版本号已按语义化版本规范更新
- [ ] CHANGELOG 已更新，包含所有用户可见的变更
- [ ] 数据库迁移脚本已准备（如适用）
- [ ] 配置文件变更已文档化
- [ ] Breaking Changes 已明确标注并提供迁移指南

### 4. 构建与部署

- [ ] 生产环境构建成功，产物大小合理
- [ ] 环境变量和配置已就绪
- [ ] 部署脚本已测试
- [ ] 回滚方案已准备
- [ ] 灰度/金丝雀发布策略已确认

### 5. 文档

- [ ] API 文档已更新（如适用）
- [ ] 用户文档已更新
- [ ] README 中的安装/使用说明仍然准确
- [ ] 已知问题已记录

### 6. 监控与告警

- [ ] 关键指标的监控已配置
- [ ] 错误告警规则已设置
- [ ] 日志收集已就绪
- [ ] 性能基线已记录

## 输出格式

```
## 发布就绪评估

### 总体状态：READY / NOT READY / CONDITIONAL

### 检查结果
| 类别 | 通过 | 失败 | 跳过 | 备注 |
|------|------|------|------|------|

### 阻塞项
[列出所有阻塞发布的问题]

### 风险项
[列出非阻塞但需关注的风险]

### 发布建议
[具体的发布步骤和时间窗口建议]
```
